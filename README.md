# The Art Of AI

The Art Of AI is an AI-powered content creation and productivity tool.

It allows users to generate:

- Text
- Programming code
- AI-generated images
- Creative content using a prompt library

## Technologies

- Python
- Flask
- JavaScript
- HTML
- CSS
- OpenAI API

## Features

### Text Generation
Users can enter a prompt and generate written content.

### Code Generation
Users can request programming solutions and explanations.

### Image Generation
Users can describe an image and generate it using AI.

### Prompt Library
The application provides ready-made prompts to help users get started.
